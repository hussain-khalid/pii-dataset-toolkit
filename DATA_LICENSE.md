# Data licence

All data generated by this project (text records, document images, annotations,
the benchmark files and the generated dataset card) is **fully synthetic**. It is
released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/):
you may copy, modify and use it for any purpose without asking.

The source code is licensed separately under the MIT licence (see `LICENSE`).

The licence value written into every record's provenance block is set by the
`LICENSE` constant in `piikit/build_release.py`. If you change the data licence,
change it there and rebuild the release.
